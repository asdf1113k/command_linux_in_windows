# description
набор батников(*.bat файлов) которые называются как команды в linux, которые просто запускают команды PowerShell

# install
/*не проверял это на windows но обязательно проверю*/
```bash
git clone https://github.com/asdf1113k/command_linux_in_windows.git
```
дальше нужно прописать путь к папке comand_linux_in_windows в переменной PATh

```
setx /M path "%path%;C:\ваш\путь\до\папки\command_linux_in_windows"
```

| Назначение | Windows (CMD) | Linux | Изучено |
| :--- | :--- | :--- | :---: |
| Справка по команде | `help` или `<команда> /?` | `man <команда>`, `whatis`, `apropos` | [ ] |
| Текущая директория | `cd` | `pwd` | [ ] |
| Сменить директорию | `cd <путь>` | `cd <путь>` | [ ] |
| Список файлов и папок | `dir` | `ls -la` | [ ] |
| Создать папку | `mkdir <имя>` или `md` | `mkdir <имя>` | [ ] |
| Удалить пустую папку | `rmdir <имя>` или `rd` | `rmdir <имя>` | [ ] |
| Удалить папку с содержимым | `rmdir /s /q <имя>` | `rm -rf <имя>` | [ ] |
| Копировать файлы | `copy <источник> <цель>` | `cp <источник> <цель>` | [ ] |
| Переместить / переименовать | `move`, `ren` | `mv` | [ ] |
| Удалить файл | `del <файл>` | `rm <файл>` | [ ] |
| Показать содержимое файла | `type <файл>` | `cat <файл>`, `less <файл>` | [ ] |
| Поиск текста в файлах | `findstr "текст" <файл>` | `grep "текст" <файл>` | [ ] |
| Поиск файлов | `dir /s /b *маска*` | `find <путь> -name "*маска*"` | [ ] |
| Очистить экран | `cls` | `clear` или `Ctrl + L` | [ ] |
| Список процессов | `tasklist` | `ps aux` | [ ] |
| Завершить процесс | `taskkill /pid <PID>` или `/im <имя>` | `kill <PID>` или `killall <имя>` | [ ] |
| Сетевые интерфейсы и IP | `ipconfig /all` | `ip a` или `ifconfig` | [ ] |
| Проверка доступности узла | `ping <адрес>` | `ping <адрес>` | [ ] |
| Маршрут до узла | `tracert <адрес>` | `traceroute <адрес>` | [ ] |
| Выключение / перезагрузка | `shutdown /s /t 0`, `shutdown /r /t 0` | `poweroff`, `reboot` | [ ] |
